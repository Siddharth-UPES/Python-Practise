# 🐍 Python Practise

Welcome to my **Python Practice** repository — a collection of basic Python programs crafted while learning the core concepts of Python programming.

---

## 📚 Overview

This repo contains beginner-friendly Python scripts that demonstrate:

- 🧮 Arithmetic operations
- 🔄 Variable swapping
- 📥 Taking user input
- 📋 List operations
- 🧵 String manipulation and concatenation
- ➕ Working with libraries
- 📊 Arrays and slicing
- 🧠 Logical thinking through mini examples
